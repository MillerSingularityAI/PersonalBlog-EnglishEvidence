# Miller Salcedo Portfolio English Skills

A personal development project and academic portfolio designed to document my English language learning journey. This web-based portfolio presents a collection of activities, reflections, multimedia evidence (audio, video, documents, mind maps), and coursework demonstrating my progress from B1 to B2 level in accordance with the CEFR standards.

## Project Description

This portfolio is built using modern **HTML**, **CSS** (Vanilla), and **JavaScript**, adopting a "Neon Futurista" dark-mode aesthetic. It serves as an interactive repository of my language acquisition process in the SENA program (2025–2026), replacing traditional static documents with an organized, filterable, and visually engaging web interface.

Key features include:
- **Responsive Design**: Adapts beautifully to desktop and mobile screens.
- **Dynamic Filtering**: Easily navigate entries by tags such as *PDF*, *Video*, *Audio*, *Mind Map*, *Writing*, and *Speaking*.
- **Integrated Media**: Embedded YouTube videos, Vocaroo audio files, Google Drive PDFs, and Figma mind maps to provide direct access to the evidence.
- **Rich Aesthetic**: Utilizes CSS variables, glassmorphism, and neon gradients to create a premium, engaging user experience.
- **Dark/Light Mode**: User preference toggle for day and night viewing.

## Technologies Used
- HTML5
- Vanilla CSS3
- Vanilla JavaScript
